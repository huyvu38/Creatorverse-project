# 💫 Creatorverse

Creatorverse is a simple content creator directory web app built with **React (Vite)** and **Supabase**. It allows users to create, view, edit, and delete content creators in a clean and interactive interface.

---

## 🚀 Features

- View all content creators
- View a single content creator
- Add a new content creator
- Edit existing content creators
- Delete content creators
- Visit external creator links
- Responsive UI with Tailwind CSS

---

## 🛠️ Tech Stack

- React (Vite)
- React Router DOM
- Supabase (Database & API)
- Tailwind CSS
